# Unreal Equipment Room

**Project 3 of a three-project 3D portfolio.** An interactive Unreal Engine equipment room that brings together an original industrial control panel and a Blender-authored data centre rack installation and maintenance demonstrator.

**Status:** Planned. This README defines the build scope and the evidence the finished project will include.

## Portfolio projects

| Project | Deliverable |
| --- | --- |
| 1. Industrial Control Panel | Standalone Blender hard-surface asset with editable source, UVs, a high-to-low bake, 4K metal-rough textures, and a turntable. |
| 2. 3D Data Centre Rack Installation and Maintenance Demonstrator | Standalone Blender project inspired by hands-on IT experience. An animated equipment installation and removal sequence demonstrates rail alignment, clearances, and serviceable moving parts. |
| 3. Unreal Equipment Room | Playable scene integrating assets from projects 1 and 2, with lighting, collisions, interactive controls, and real-time validation. |

The companion source repositories will be linked here when available.

## Intended walkthrough

1. Enter the room and approach the control panel.
2. Start the demonstration and observe a rack-mounted unit align with the rails and slide into place.
3. View the removal sequence and reset the station for another run.

## Planned portfolio evidence

- Unreal project files and a short gameplay walkthrough.
- Asset credits identifying personally modeled and animated work, with links to the editable Blender sources and exchange files.
- Import checks comparing scale, clip duration, and key contact frames against the Blender source.
- A verification pass covering collision geometry, rail clearance, lighting, repeated start and reset behavior, and measured frame time with the hardware and resolution recorded.
